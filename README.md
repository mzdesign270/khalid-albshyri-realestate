# موقع الأستاذ خالد البشيري | وسيط عقاري معتمد في جدة
### Khalid Al-Bshyri | Licensed Luxury Real Estate Broker Website Prototype

موقع تعريفي وتسويقي فاخر (Single Page Application) مبني بأحدث معايير الويب الراقية (Saudi Luxury Aesthetic)، مخصص للوساطة العقارية وشقق التمليك تحت الإنشاء والاستثمار في مدينة جدة.

## 🌟 أبرز مميزات الموقع (Key Features)

1. **الهوية البصرية الفاخرة (Saudi Luxury Identity)**:
   - لوحة ألوان مستوحاة من الفخامة السعودية: الأخضر الزمردي `#0B5D3B`، وتدرج الذهب الشامباني `#C9A24B` إلى `#E8D08A`، والأسود الليلي العميق `#07110D`، والعاجي `#F7F4EC`.
   - خطوط طباعية عربية معتمدة: عناوين بالخط العريض **Tajawal**، والنصوص بخط **IBM Plex Sans Arabic**. وللإنجليزية: **Playfair Display** و **Inter**.
   - نمط هندسي إسلامي وسعودي مذهب وخفيف بنسبة عتامة 4% كخلفية فاخرة، مع أيقونة النخلة والسيفين كفواصل جمالية.

2. **دعم كامل للغتين (العربية RTL والإنجليزية LTR)**:
   - الوضع الافتراضي: اللغة العربية واتجاه اليمين إلى اليسار (RTL).
   - زر تبديل اللغة الفوري في النافبار يحول كل النصوص والمصطلحات والاتجاهات فورياً مع حفظ التفضيل في المتصفح.

3. **الوضع الليلي والنهاري (Dark / Light Theme)**:
   - الوضع الليلي هو الافتراضي (Dark Obsidian Luxury).
   - زر تبديل سلس بانتقال 400ms مع حفظ الخيار في `localStorage`.

4. **تأثيرات وتفاعلات حركية متقدمة (Ultra-Smooth Interactions)**:
   - شاشة افتتاحية ذهبية متحركة ترسم شعار `KB` قبل الدخول للموقع.
   - تأثير ذرات الذهب المتطايرة (`Gold Dust Particles`) عبر HTML5 Canvas في واجهة الموقع.
   - كروت زجاجية فاخرة بتقنية ثلاثية الأبعاد تفاعلية مع حركة الفأرة (`3D Tilt on Hover`).
   - أزرار مغناطيسية تنجذب لمؤشر الماوس مع تأثير النبض الذهبي (`Pulse Glow`).
   - مؤشر توهج ذهبي ناعم يتبع الماوس على أجهزة الكمبيوتر (`Cursor Glow`).
   - شريط تقدم القراءة والنزول الذهبي أعلى الصفحة.
   - إشعار لحظي متحرك (`Live Ticker Toast`) بآخر الحجوزات واستفسارات العملاء.

5. **أقسام الموقع الكاملة (13 قسماً متكاملاً)**:
   - **الواجهة الرئيسية (Hero)**: خلفية سينمائية ساحلية لجدة مع زووم بطيء، نص جذاب وشارات الاعتماد الرسمي ورخصة فال.
   - **شريط الأرقام والإحصائيات المتحرك**: عدادات تفاعلية (+120 عميل، +15 مشروع، +5 سنوات، 100% رضا مع حلقة دائرية مفرغة).
   - **خدماتنا (4 كروت زجاجية)**: بيع، تأجير وإدارة أملاك، شقق تمليك تحت الإنشاء، استشارات استثمارية.
   - **المشروع المميز (برج اللؤلؤة - جدة)**: معرض صور مع سلايدر تفاعلي، مواصفات، شريط الوحدات المتبقية (12 من 40)، وخريطة تفاعلية لموقع جدة، وزر تحميل البروشور.
   - **نافذة تحميل البروشور (Brochure Modal)**: تطلب رقم الجوال وترسل الطلب فوراً.
   - **لماذا نحن (6 كروت)**: وسيط معتمد، شفافية، متابعة حتى الإفراغ، عوائد مدروسة، رد سريع، بلا عمولات خفية.
   - **توثيق رخصة فال (REGA)**: كارت محاكاة رسمي لرخصة الهيئة العامة للعقار مع زر للتحقق في المنصة الحكومية.
   - **خطوات التملك (Timeline)**: خط زمني رأسي مضيء يوضح مراحل شراء الشقة في 4 خطوات واضحة.
   - **من نحن (About)**: قصة الوسيط الشخصية، إطار الصورة المتوهج بدوران ليزري، شارات الاعتماد، وتغذية ريلز إنستغرام لـ `@albshyry2030`.
   - **حاسبة الاستثمار والأقساط**: حاسبة تفاعلية مع أشرطة تمرير لحساب القسط الشهري والعائد السنوي المتوقع (9.5%).

## 🚀 طريقة التشغيل (How to Run)

المشروع مبني ليكون فائق الخفة ومستقلاً تماماً:
1. قم بفك الضغط عن ملف `khalid-albshyri-realestate.zip`.
2. اضغط نقراً مزدوجاً على ملف `index.html` لفتحه في أي متصفح (Chrome, Safari, Edge, Firefox).
3. يعمل فورياً على أجهزة سطح المكتب والهواتف الذكية والأجهزة اللوحية دون الحاجة إلى تثبيت أي برامج أو خوادم.
4. يمكن رفعه مباشرة على أي استضافة (مثل cPanel, Vercel, Netlify, Firebase Hosting, GitHub Pages).
